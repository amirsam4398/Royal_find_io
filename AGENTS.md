IMPORTANT DEVELOPMENT RULES:

1. Never delete existing working features.
2. Never rewrite the project from scratch.
3. Preserve the existing folder structure.
4. Inspect existing code before modifying it.
5. Make incremental changes.
6. Never overwrite working files without checking them.
7. Keep the project compatible with Vercel.
8. Never commit API keys or secrets.
9. Run npm run build after significant changes.
10. Document every architectural change.

Before development:
- Read AI_CONTEXT.md
- Read docs/PROJECT_STATUS.md
- Inspect package.json
- Inspect existing source files

All AI developers must follow these rules.
